Especificação de Engenharia: Banco de Dados

Projeto: Ecossistema de Hipertrofia e Gestão de Atletas
SGBD: PostgreSQL (Compatível com instâncias Docker e Nuvem)
Padrão de Chaves: UUID v4 (Suporte a Arquitetura Offline-First)
Status: Aprovado para Desenvolvimento

1. Visão Geral da Arquitetura

O banco de dados foi projetado para desacoplar rigorosamente o Planejamento (rotinas e fichas ideais) da Execução Real (histórico de cargas e repetições). A infraestrutura prevê alto volume de escrita na tabela de séries e suporte nativo a operações offline no aplicativo mobile.

2. Matriz de Relacionamentos (ERD)

Entidade Origem Cardinalidade Entidade Destino Chave Estrangeira (FK) Regra de Integridade
usuarios 1 : N planos_treino usuario_id CASCADE ao deletar usuário
planos_treino 1 : N dias_treino plano_treino_id CASCADE ao deletar plano
dias_treino 1 : N dias_treino_exercicios dia_treino_id CASCADE ao deletar dia
exercicios_catalogo 1 : N dias_treino_exercicios exercicio_id RESTRICT (impede remoção em uso)
usuarios 1 : N sessoes_treino usuario_id CASCADE ao deletar usuário
sessoes_treino 1 : N series_executadas sessao_treino_id CASCADE ao deletar sessão
exercicios_catalogo 1 : N series_executadas exercicio_id RESTRICT
usuarios 1 : N avaliacoes_corporais usuario_id CASCADE
usuarios 1 : N exames_biomarcadores usuario_id CASCADE
usuarios 1 : 1 (por dia) checkin_diario_lifestyle usuario_id CASCADE (Unique: user + data)

3. Dicionário de Tabelas e Atributos

Módulo 1: Motor de Treino

Tabela Campo Tipo Descrição
exercicios_catalogo id UUID (PK) Identificador único do exercício.
nome VARCHAR(150) Nome oficial (Ex: Supino Reto com Barra).
grupo_muscular VARCHAR(50) Grupamento principal para contagem de volume semanal.
dias_treino_exercicios dia_treino_id UUID (FK) Vínculo com a ficha (Treino A, B, C).
exercicio_id UUID (FK) Vínculo com o catálogo de exercícios.
ordem INT Ordem de execução para a tela do app (1, 2, 3...).
series_alvo / reps_alvo INT Metas de séries e repetições planejadas.

Módulo 2: Execução e Métricas de Hipertrofia

Tabela Campo Tipo Descrição
sessoes_treino id UUID (PK) Identificador da sessão iniciada.
data_inicio / data_fim TIMESTAMPTZ Cálculo automático de duração total de treino.
rpe_geral INT (1-10) Percepção subjetiva de esforço geral da sessão.
series_executadas tipo_serie ENUM AQUECIMENTO, TRABALHO, DROP_SET, FALHA.
peso NUMERIC(6,2) Carga utilizada em kg (permite decimais para anilhas fracionadas).
repeticoes INT Repetições válidas executadas.
rir INT (0-10) Repetições na reserva até a falha concêntrica.
tempo_descanso_segundos INT Tempo real de descanso cronometrado pelo app.

Módulo 3: Saúde, Biomarcadores e Lifestyle

Tabela Campo Tipo Descrição
avaliacoes_corporais peso_kg, percentual_gordura, medidas NUMERIC Evolução antropométrica e perimétrica.
exames_biomarcadores resultados JSONB Estrutura flexível para múltiplos marcadores (Testosterona, Vitamina D, etc.).
checkin_diario_lifestyle sono, estresse, doms, macros INT / NUMERIC Variáveis de prontidão biológica e recuperação do atleta.

4. Decisões Críticas de Engenharia

  • Chaves Primárias UUID v4: Permitem que o aplicativo gere registros localmente sem conexão com a internet, sincronizando com a API via fila sem gerar colisões de chave primária.
  • Indexação Composta: O índice idx_series_exercicio_sessao garante busca em O(log n) para recuperar as cargas anteriores no início de cada exercício.
